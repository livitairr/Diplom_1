🧪 Юнит-тесты для модели бургера в Stellar Burgers
Этот проект представляет собой набор юнит-тестов для проверки бизнес-логики приложения по сборке бургеров в Stellar Burgers.

📌 Цели проекта
1. Покрытие классов модели (Bun, Burger, Ingredient, IngredientType) юнит-тестами
2. Использование Mockito, Junit 4 и параметризации там, где это оправдано
3. Генерация отчёта покрытия тестами с помощью Jacoco
4. Достижение уровня покрытия не менее 70%
5. Отделение логики от тестов и соблюдение принципов написания чистых и независимых тестов


🔧 Технологии и инструменты
1. Java 11
2. JUnit 4
3. Mockito
4. Jacoco (для покрытия кода)
5. Maven


🧪 Запуск тестов
mvn clean test


✅ Результаты
1. Все тесты проходят успешно
2. Покрытие кода по Jacoco составляет не менее 70%
3. В тестах используются моки, стабы и параметризация, где это необходимо
4. Названия тестов и переменных соответствуют принципам читаемого кода
5. Проект оформлен в соответствии с Maven и Java best practices
6. Отчёт Jacoco приложен к Pull Request'у
